# G1: compact resolved GC targets

Independent baseline f8638be9. Worktree /Users/callen/.codex/worktrees/mold-g1-compact-gc-targets/mold; branch codex/mold-g1-compact-gc-targets.

The same-baseline CPU profile places section-GC visitation among rust-analyzer's leading CPU costs. Regular relocation traversal loads a file-local SymbolId, the larger symbol record, the symbol's file/origin, and then the target section or fragment through context storage. The prototype builds a 16-byte typed target cache indexed by SymbolId before marking. It is not an adjacency graph: original relocations remain the edges, and the original atomic liveness/visited state remains authoritative. Impact 4, confidence 4, effort 3: score 5.3.

Targets are None, borrowed InputSection, borrowed SectionFragment, DsoId, or an uncached special SymbolId. References remain stable for the immutable marking phase. DSO precedence and fragment behavior match the existing regular-edge traversal. Symbols whose names actually match a start/stop map entry use the original special handling, preserving combined ordinary-target and section-name fanout semantics. Exception-frame relocations retain their existing path. ARM exidx, root collection, sweep, unreachable DSO removal, and output ordering are unchanged. There is no new unsafe code.

The full cache build and its allocation are included in elapsed/CPU/RSS measurements under a build_gc_targets timer. Memory grows by about 16 bytes per symbol for the duration of GC. This may be a poor tradeoff when many symbols are not visited; measurements must include its preparation cost. Golden output validation, native GC/DSO/exception tests, and corpus coverage remain required. Root coordinates performance runs.

Decision after independent 50-pair confirmation: reject. Rust-analyzer wall -1.9% (95% interval -4.0% to +1.2%) and CPU +0.1% (-1.3% to +1.6%); stripped rust-analyzer wall -1.3% (-3.1% to +0.4%) and CPU +0.3% (-1.3% to +1.8%). lld and Clang were neutral. The initial latency hint weakened and no repeatable efficiency gain justified a whole-symbol target cache. Preserve the independent prototype for review; do not include in omnibus.
